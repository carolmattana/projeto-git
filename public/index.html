Esta página foi feita por mim para praticar gerência de configuração: controle de versões com Git, uso de branches, merge request, integração contínua e publicação automática no GitLab Pages. Abaixo eu apresento três ferramentas de qualidade de software que ajudam a encontrar erros cedo e a manter o código confiável.

Três ferramentas de qualidade de software

SonarQube

Finalidade: análise estática de código. Ele revisa o código automaticamente e aponta bugs, vulnerabilidades de segurança e "code smells" (trechos mal escritos), ajudando a melhorar a qualidade antes de o programa ir para produção.

sonarsource.com/products/sonarqube

JUnit

Finalidade: framework de testes unitários para Java. Permite escrever pequenos testes automáticos que verificam se cada parte do código funciona como esperado, evitando que mudanças novas quebrem o que já estava certo.

junit.org

Jenkins

Finalidade: servidor de integração contínua (CI/CD). A cada mudança enviada ao repositório, ele compila, roda os testes e publica a aplicação de forma automática, dando um retorno rápido sobre a qualidade da versão.

jenkins.io

Ferramentas de teste

Seção criada para atender a issue de melhoria. Cada ferramenta tem nome, finalidade e link.

Selenium

Finalidade: automação de testes de interface (E2E). Simula um usuário navegando no site pelo navegador para checar se as telas funcionam.

selenium.dev

Postman

Finalidade: teste de APIs REST. Permite enviar requisições e conferir se as respostas do servidor estão corretas.

postman.com

Apache JMeter

Finalidade: teste de carga e desempenho. Simula muitos usuários ao mesmo tempo para medir como o sistema se comporta sob pressão.

jmeter.apache.org
